# Changelog

## 0.1.0 — release candidate

- Added a Chinese top-level Blockbench menu and resizable generator dialog.
- Added PNG, JPEG, and WebP decoding with alpha-aware statistics.
- Added cancelable row and pixel ModelPlan generation and a project-independent 3D preview.
- Added one-Cube-per-pixel workspace generation with six-face texel UV mapping and a single Undo edit.
- Added count limits, performance warnings, tests, and documentation.
